# UI Guidelines

## Accessibility baseline

- Provide a visible-on-focus **skip link** to main content.
- Ensure interactive controls have explicit `type="button"` where needed.
- Use `aria-expanded` + `aria-controls` for menu toggles.
- Keep heading hierarchy sequential (`h1`→`h2`→`h3`).
- Use descriptive `alt` text for all meaningful images.

## Visual consistency

- Preserve existing gradient palette and spacing scale.
- Keep motion subtle and avoid large layout shifts on hover.
- Ensure primary/secondary CTA contrast remains legible.

## Review checklist

- Keyboard-only tab flow works end-to-end.
- Focus indicator is visible on dark background.
- Mobile viewport does not overflow horizontally.
